# Writing codes: 10 codes that make Claude stop sounding like AI

Type a code, then paste your draft. It's one free Claude skill: [writing-codes](../../skills/writing-codes/SKILL.md).

| # | Code | What Claude does |
| --- | --- | --- |
| 1 | Plain | Everyday words, short sentences, every fact kept |
| 2 | Cut 30% | The same message in about 30% fewer words |
| 3 | My voice | Learns your style from two or three things you wrote, then rewrites in it |
| 4 | No clichés | Removes what reads as machine-written ("delve", "elevate", "seamless"…) |
| 5 | Hook first | Moves the most interesting line to the top |
| 6 | Text message | Rewrites it the way you'd text a friend |
| 7 | Read aloud | Fixes every sentence that trips when read out loud |
| 8 | Show me | Flags vague claims and asks for the real example; never makes one up |
| 9 | Firmer | No hedges or apologies; polite, clear and direct |
| 10 | Red pen | Marks it up like an editor and ranks the five best fixes |

## Install

- **Claude app:** download the [writing-codes](../../skills/writing-codes) folder, zip it, and upload the zip in Customize > Skills (works on every plan).
- **Claude Code:** `npx skills add alisadiq-ai/agi-ali-freebies`, or copy the folder into `~/.claude/skills/`.
