# The 5 free AI tools worth keeping

@agiguy.ai has shown over thirty free tools. These five got the most saves on the account (Instagram counts, November 19, 2026). Keep these and delete the rest.

| # | Tool | What it does | Get it | Good to know |
| --- | --- | --- | --- | --- |
| 1 | Learning codes | Type a code before any topic: ELI5, 80/20, Feynman, quiz me, flashcards, pre-mortem, mind map, first principles, analogy, steelman | [learn-anything skill](https://github.com/alisadiq-ai/agi-ali-freebies/tree/main/skills/learn-anything) | A free Claude skill. Works in Claude and Claude Code |
| 2 | MarkItDown | Turns PDF, Word, PowerPoint and Excel files into clean Markdown text for AI | [microsoft/markitdown](https://github.com/microsoft/markitdown) | From Microsoft, MIT licence. Install with `pip install 'markitdown[all]'` |
| 3 | Graphify | Maps your project (code, docs, PDFs) into a knowledge graph your coding agent can query, plus a clickable graph.html | [Graphify-Labs/graphify](https://github.com/Graphify-Labs/graphify) | Apache-2.0. Parses code on your machine with no AI calls. Type `/graphify` |
| 4 | Ollama | Connects Claude Code to open models running on your own computer | [ollama/ollama](https://github.com/ollama/ollama) and its [Claude Code guide](https://docs.ollama.com/integrations/claude-code) | Run `ollama launch claude`. Its pricing page says running models on your own hardware is always unlimited. These are open models, not Anthropic's Claude |
| 5 | Stickman Video Director | Turns any script into a stick-figure video with voiceover, captions and sound, in 11 styles | [kaomei/stickman-video-director](https://github.com/kaomei/stickman-video-director) | MIT licence. The tool is free; it runs on your own AI and voice API keys, which may cost money |
